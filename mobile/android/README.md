TransitGo Android Skeleton (Training)
====================================

Implements
- FR-034 Bilingual UI with runtime language switch (cross-cutting)
- Jira: TRGO-12 “Android app skeleton with tab navigation and i18n setup”
- Confluence: TRGO 5.1 Design System – https://epsylum.atlassian.net/wiki/spaces/TRGO/pages/688146

Scope
- Minimal Jetpack Compose app with two tabs (Planner, Tickets)
- Localised strings for English (en) and Slovak (sk)

Run
- Open this folder in Android Studio (Giraffe+)
- Sync Gradle and run on an Android 10+ emulator
