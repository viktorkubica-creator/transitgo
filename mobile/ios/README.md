TransitGo iOS Skeleton (Training)
=================================

Implements
- FR-034 Bilingual UI with runtime language switch (cross-cutting)
- Jira: TRGO-11 “iOS app skeleton with tab navigation and i18n setup”
- Confluence: TRGO 5.1 Design System – https://epsylum.atlassian.net/wiki/spaces/TRGO/pages/688146

Scope
- Minimal SwiftUI app with two tabs (Planner, Tickets)
- Localisable strings for English (en) and Slovak (sk)

Run
- Open `TransitGoApp/Package.swift` in Xcode (SwiftPM)
- Select an iOS Simulator and Run
